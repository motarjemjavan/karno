# 🚗 کارنو - دستیار هوشمند نگهداری خودرو

**کارنو** یک اپلیکیشن وب پیش‌رونده (PWA) برای مدیریت سرویس‌ها و نگهداری خودرو است که به صورت کاملاً آفلاین کار می‌کند.

## ✨ ویژگی‌ها

- 📱 **نصب روی گوشی** - مانند یک اپلیکیشن واقعی
- 📴 **کاملاً آفلاین** - بدون نیاز به اینترنت
- 🌙 **حالت تاریک** - با تشخیص خودکار تم سیستم
- 💾 **ذخیره‌سازی پیشرفته** - با IndexedDB (بدون محدودیت حجم)
- 🔔 **یادآورهای هوشمند** - هشدار زرد و قرمز بر اساس کیلومتر
- 📊 **خروجی اکسل** - دانلود سوابق به فرمت CSV
- 📤 **پشتیبان‌گیری** - دانلود و بازیابی فایل JSON
- 📳 **لرزش گوشی** - Haptic Feedback برای تجربه بهتر
- 🎨 **رابط کاربری زیبا** - طراحی مدرن و کاربرپسند

## 🚀 نصب و استفاده

### روش ۱: GitHub Pages (پیشنهادی)

1. این ریپازیتوری را Fork کنید
2. به **Settings** → **Pages** بروید
3. Branch را روی **main** و پوشه را روی **/ (root)** قرار دهید
4. لینک `https://motarjemjavan.github.io/karno/` را در گوشی باز کنید
5. از منوی مرورگر (⋮) گزینه **Install app** را بزنید

### روش ۲: Netlify Drop (سریع‌ترین)

1. به [app.netlify.com/drop](https://app.netlify.com/drop) بروید
2. فایل‌ها را Drag & Drop کنید
3. لینک دریافتی را در گوشی باز کنید و نصب کنید

## 📱 نحوه استفاده

1. **ثبت مشخصات خودرو**: در بخش تنظیمات، نام و پلاک خودرو را وارد کنید
2. **بروزرسانی کیلومتر**: هر هفته کیلومتر فعلی را وارد کنید
3. **ثبت سرویس**: پس از هر تعمیر یا سرویس، آن را ثبت کنید
4. **تعریف یادآور**: دوره‌های تعویض روغن، لنت و... را تعریف کنید
5. **پشتیبان‌گیری**: مرتباً از تنظیمات، فایل پشتیبان دانلود کنید

## 🛠️ تکنولوژی‌ها

- HTML5, CSS3, JavaScript (Vanilla)
- IndexedDB برای ذخیره‌سازی
- Service Worker برای قابلیت آفلاین
- Web App Manifest برای PWA
- Vazirmatn Font
